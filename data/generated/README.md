# 生成课程数据

## 当前版本

- 课程：数据结构与算法基础
- 知识库版本：`course-corpus-v001`
- 知识片段数：960
- 章节数：16
- 测试集版本：`test-v001`
- 测试问题数：150
- 生成脚本：`scripts/generate_course_dataset.py`

## 来源原则

课程章节主题参考公开课程页面，但正文由本项目自撰生成，不复制 MIT、Princeton 或 OpenDSA 的讲义、教材、题目和答案。公开页面只用于确定课程覆盖范围和概念组织方式。

## 使用限制

这些数据是论文实验的初始数据版本。正式实验前需要：

1. 人工抽查知识片段准确性；
2. 检查概念之间是否存在重复或表述偏差；
3. 复核 150 条问题的标准答案和 gold 片段；
4. 由导师确认课程范围和数据版本；
5. 记录修订后的版本号。
