# 测试集构建与标注

## 数量要求

- 开发集：先制作 30–50 条，用于调试和参数选择；
- 正式测试集：不少于 150 条；
- 四类主问题尽量均衡，每类建议至少 35 条；
- 如加入 `unanswerable`，单独统计，不与四类主问题混合。

## 四类问题

1. `term_definition`：术语定义；
2. `principle_explanation`：原理解释；
3. `process_steps`：流程步骤；
4. `confusable_concepts`：易混辨析。

## 标注规则

- 每条问题至少标注一个 `gold_chunk_id`；
- 能共同支持答案的多个片段全部标注；
- 只出现关键词但不能支持答案的片段不标注为 gold；
- 保存标准答案和标注说明；
- 至少抽取 20% 问题进行第二人复核；
- 测试集冻结后不得根据模型结果修改问题或答案。

## 推荐数量

| 类型 | 建议数量 |
|---|---:|
| 术语定义 | 35–40 |
| 原理解释 | 35–40 |
| 流程步骤 | 35–40 |
| 易混辨析 | 35–40 |
| 合计 | 不少于 150 |
