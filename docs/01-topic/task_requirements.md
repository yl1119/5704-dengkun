# 任务要求

## 最低完成要求

1. 确定至少一个具体高校课程领域和合法资料来源。
2. 独立构建规范课程知识库，包含约 800–2000 个知识片段，完成清洗、去重、切分、章节、元数据和版本登记。
3. 构建不少于 150 条问题的独立测试集，按术语定义、原理解释、流程步骤、易混辨析分类。
4. 分别实现 BM25 关键词检索和 Dense 向量检索。
5. 至少实现一种 Hybrid 方法：经过归一化的分数加权融合或 RRF；建议两种均实现以形成融合方式消融。
6. 先冻结统一评测脚本，再统一比较 Recall@1/3/5/10、Hit Rate@1/3/5/10、MRR 和检索延迟。
7. 完成基础 RAG 问答闭环，比较答案准确性、完整性、faithfulness 和引用正确性。
8. 研究 `alpha∈[0,1]` 的权重曲线，或研究 RRF 的 `k` 参数，并解释较优区间。
9. 按四类问题统计，解释术语型问题与语义改写型问题对稀疏/稠密检索的不同偏好。
10. 完成融合方式、权重和 Top-k 消融实验。
11. 分析混合检索反而变差的典型案例。
12. 完成 5–8 页 Baseline 与问题分析报告。
13. 完成知识库、测试集、统一评测脚本、结果表、权重曲线图、问答系统演示和毕业论文。

## 拓展目标

- rerank 重排序；
- query rewrite 查询改写；
- 基于问题类型、检索分歧或置信度的动态融合策略；
- 不同 embedding 模型比较；
- 不同文档切分策略比较；
- 不可回答问题检测。

## 未来 2–3 周任务

### 1. 仓库与题目冻结

- 补全专业和课程范围；
- 与导师确认题目；
- 更新 `topic_confirm.md`；
- 登记课程资料来源和许可证。

### 2. 文献核验

- 从候选文献中筛选 10–15 篇核心文献；
- 核验作者、年份、出处和 DOI；
- 至少精读 5 篇并填写阅读卡；
- 只有核验后的文献可进入最终论文。

### 3. 数据与测试集

- 整理首批课程文档；
- 完成清洗和切分；
- 制作四类问题的开发集，并为正式 150 题测试集建立标注规范；
- 标注 `gold_doc_ids` 和 `gold_answer`；
- 后续扩充为不少于 100 条的正式独立测试集。

### 4. Baseline

- 先跑通 BM25；
- 再跑通 Dense；
- 先冻结评测协议，再在相同切分、测试集和判定标准下统一比较；
- 不要在 Baseline 完成前优先开发复杂改进算法。

### 5. 第一版实验设计与报告

- 完成 Baseline、主实验、参数/消融、失败案例四类实验设计；
- 形成 5–8 页 Baseline 与问题分析报告；
- 报告初始结果、主要问题和下一步改进理由。
