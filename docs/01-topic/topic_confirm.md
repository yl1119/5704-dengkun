## 研究对象

本论文研究高校课程知识问答系统中的检索增强生成方法，重点比较关键词检索、向量检索和混合检索在课程知识召回及最终问答质量方面的差异。

## 课题定位

本课题是方法研究型课题，主要创新点应落在稀疏检索与稠密检索的融合机制、分数归一化、融合权重和题型差异分析上。问答系统演示属于交付物，但不应以界面数量或系统功能堆叠替代检索方法研究。

## 研究问题

1. BM25 与 Dense Retrieval 在高校课程知识库上的检索效果有何差异？
2. 分数加权融合与 RRF 能否在统一测试集上稳定优于单一路线？
3. 加权融合的 `alpha` 或 RRF 的 `k` 参数如何影响检索与问答质量？
4. 术语定义、原理解释、流程步骤和易混辨析四类问题下，三种检索分别有哪些优势和失败模式？
5. 检索质量变化如何影响答案准确性、完整性和 faithfulness？

## 研究边界

1. 正式实验前冻结课程范围、资料来源和许可证，知识库目标为 800–2000 个片段。
2. 测试集与知识库分开管理，不使用正式测试集反复调参。
3. 正式测试集不少于 150 条，并按四类问题标注。
4. 先完成 BM25、Dense 和 Hybrid 三条基础链路，再开展 rerank、query rewrite 和动态融合。
5. 第三方模型、框架和代码必须注明来源、版本、许可证和本人修改内容。
