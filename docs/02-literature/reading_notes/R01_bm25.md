# 文献阅读卡：R01 BM25

## 基本信息

- 标题：The Probabilistic Relevance Framework: BM25 and Beyond
- 作者：Stephen Robertson; Hugo Zaragoza
- 年份：2009
- 出处：Foundations and Trends in Information Retrieval
- DOI：10.1561/1500000019

## 研究问题

如何在概率相关性框架下改进词法匹配和文档排序。

## 方法

BM25 使用查询词在文档中的频率、逆文档频率和文档长度归一化等因素计算相关性。

## 与本人课题的关系

为 BM25 基线、`k1`、`b` 和稀疏检索优势分析提供理论依据。

## 对本人实验的启发

课程术语、章节编号和专有名词可能更依赖精确词项匹配，应在四类问题中单独报告 BM25 表现。
