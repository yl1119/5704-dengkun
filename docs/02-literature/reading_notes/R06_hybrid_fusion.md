# 文献阅读卡：R06 Hybrid Fusion

## 基本信息

- 标题：An Analysis of Fusion Functions for Hybrid Retrieval
- 作者：Sebastian Bruch; Siyu Gai; Amir Ingber
- 年份：2024
- 出处：ACM Transactions on Information Systems
- DOI：10.1145/3596512

## 研究问题

不同融合函数、分数校准方式和排名融合方式对混合检索效果有何影响。

## 与本人课题的关系

这是本课题研究加权融合、分数归一化和 RRF 的核心方法参考。

## 对本人实验的启发

混合检索的提升必须同时报告融合方式、分数尺度、参数范围和计算开销，不能只报告单一最优权重。
