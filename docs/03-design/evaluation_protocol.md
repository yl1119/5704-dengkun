## 2. 公平比较约束

BM25、Dense、Weighted Hybrid 和 RRF 必须使用：

1. 同一份知识库文件；
2. 同一套文档切分结果；
3. 同一份冻结测试集；
4. 同一套 `gold_chunk_ids`；
5. 同一组 `top_k`；
6. 同一评测脚本；
7. 同一指标定义和小数保留规则；
8. 同一硬件环境下的延迟统计方法。

任何一项不一致，都不能把结果放在同一张主对比表中。

## 3. 数据划分

- 开发集：用于选择 embedding 模型、`alpha`、`rrf_k` 和 Top-k；
- 测试集：不少于 150 条，冻结后只用于最终报告；
- 测试集不得根据正式测试结果修改问题或相关文档标注；
- 如发现标注错误，记录修订原因并提升测试集版本，所有方法全部重跑。

## 4. 问题分类

使用固定枚举：

- `term_definition`：术语定义；
- `principle_explanation`：原理解释；
- `process_steps`：流程步骤；
- `confusable_concepts`：易混辨析。

如增加不可回答问题，单独标为 `unanswerable`，不与四类主问题混合统计。

## 5. 相关性判定

- 每个问题至少标注一个 `gold_chunk_id`；
- 若多个片段都能独立支持答案，应全部标注；
- 仅提到关键词但不能支持答案的片段不算相关；
- 标注争议记录在 `annotation_notes`；
- 建议抽取至少 20% 问题进行第二人复核。

## 6. 检索指标

- `Recall@1/3/5/10`；
- `HitRate@1/3/5/10`；
- `MRR`；
- 平均检索延迟；
- P95 检索延迟。

同时输出总体结果和四类问题结果。若类别数量不均衡，主表同时报告 Macro Average。

## 7. 问答指标

- Correctness：答案是否正确；
- Faithfulness：答案是否由检索上下文支持；
- 可选：引用正确性和完整性。

所有检索方法使用相同生成模型、Prompt、温度、Top-k 和最大上下文长度。

## 8. 参数选择

- Weighted Hybrid：开发集测试 `alpha = 0.0, 0.1, ..., 1.0`；
- RRF：开发集测试 `rrf_k`，建议 `{10, 20, 40, 60, 80, 100}`；
- Top-k：建议 `{1, 3, 5, 10}`；
- 只能在开发集选择参数，测试集只报告选定配置和完整曲线。

## 9. 输出文件

- 逐题检索结果；
- 总体指标表；
- 按问题类型指标表；
- 权重曲线数据 CSV；
- 权重曲线图；
- 失败案例表；
- RAG 回答与评分结果。
